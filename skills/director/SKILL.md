# 导演 Skill：CyboPal 产品片

给任何模型用的拍摄规则。数字是参数，不是形容词。机位用白名单命令 `camera.apply` 和 `arm.action`，不要手填米数，也不要拖时间线。品牌片样片对标 [Mac Studio M5](https://www.youtube.com/watch?v=3uAIqqg8ZHo)。手臂怎么动，对标戴森台灯那种「会动的臂」。

## 角色

- **编剧**：一句 logline、屏幕上的字、有没有旁白。品牌片没有旁白、没有真人。
- **导演**：段落 → 镜头。每个镜头只有 `3d` 或 `broll-code`，时长用拍数，不直接写秒。
- **摄影**：只填命名运镜和构图。求解器负责机位。
- **剪辑**：切点落在节拍上。产品镜之间的后拉速度保持同一个米/秒。

## 品牌片（`style: brand`，`look: studio-black`）

结构，按这个顺序，不要打乱：

1. **吊胃口**：关节微距和短字卡。不要出现整条手臂。
2. **技术**：底座、结构示意、一句界面。
3. **亮相**：第一次用居中的慢后拉看见整臂。
4. **动作**：机位锁死，只让产品动。展开、转竖屏、线缆入槽、点头。
5. **高潮**：半拍一刀，字和角度交替。
6. **收尾**：再一次慢后拉，然后 logo 停住。

节奏（178 BPM 时一拍约 0.337 秒）：

| 角色 | 拍数 | 秒 |
| --- | --- | --- |
| 产品静镜 `product` | 8–14 | 1.3–2.4 |
| 字卡 `text` | 2–4 | 0.3–0.7 |
| 动作镜 `action` | 6–10 | 1.0–1.7 |
| 高潮 `climax` | 0.5 | 0.17 |
| logo | 12 | 约 4 |

后拉速度锁在 **0.10 m/s**，缓动 `linear`。切到另一个角度时速度不变，所以正面切到背面仍像一口气。

光：纯黑背景，一盏主光加两盏轮廓光（冷色在后左，暖色在后右），地面低粗糙度吃一点反射。微距光圈 f/2.8，动作镜 f/5.6，其余 f/4。景深对在主体距离上。

字：大、白、黑底、几乎不飞。字卡是 `broll-code`，和三维镜头排在同一条时间线上。

## 手臂怎么拍（从戴森台灯来的）

- 产品在动，机位用 `locked`。不要追。
- 单轴动作（升降、横竖屏）用 `side`（方位角 0，正对运动平面）或 `front`（方位角 90，正对屏幕）。
- 多轴一起动用 `angle45`。
- 景别要装下起点和终点，底座和转轴留在画里。`subject: motion` 会把两头的包围盒并在一起再取景。
- 先给动作，再切一句短字。不要在动作镜上叠大字。

## 运镜和构图

运镜：`slow-pull` `slow-push` `locked` `orbit` `crane` `macro` `handheld` `over-shoulder`。

构图：`centered` `macro` `side` `front` `angle45` `low` `top` `over-shoulder`。

方位角 0 是沿 Z 看手臂的侧面，90 是沿 X 看屏幕。微距最近距离可以到 0.08 米，普通镜头不要近于 0.35 米。

博主片（`style: creator`，`look: desk`）改用 `handheld`、`top`、`over-shoulder`，可以有一句旁白。样片 1 不用这个。

## 动作

`hold` `unfold` `fold` `rise` `lower` `follow-face` `portrait` `landscape` `nod` `cable-tuck`。

`follow-face` 把屏幕送到人脸前方，默认 0.6 米，并可转到竖屏。关节限位写在 `src/product/arm.calibration.json`，那是预演默认值，不是出厂参数。

## 检查

每一镜打五分：构图、主体大小、节奏、光、衔接。均分低于 0.78 就改 `fill` 或把后拉速度拉回 0.10 m/s，再求值。没有视觉模型时用投影测量；设置 `PREVIS_VISION_URL` 后同一份分数可以交给看图的模型改。

不合格的典型原因：主体出画、微距仍小于目标占比、相邻慢后拉的速度差超过 15%、固定机位发生了位移。
